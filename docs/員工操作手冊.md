# 祥興／沂融 營運系統 — 員工操作手冊 v1.1

> 對象：所有員工（現場、設計、業務）
> 主管與老闆的功能請見《管理者操作手冊》
> 版本日期：2026-10-16

---

## 1. 登入

1. 用手機或電腦開啟公司給的系統網址
2. 輸入主管給你的 **Email 與密碼**
3. 第一次登入系統會要求**改密碼**（至少 8 碼）
4. 忘記密碼：請主管在「員工與帳號」幫你重設

> 同時在祥興、沂融兩邊工作的人，左上角點公司名稱可以切換。兩家資料完全分開。

---

## 2. 把打卡加到手機主畫面（建議第一次就做）

| 手機 | 做法 |
|---|---|
| **Android（Chrome）** | 開啟「打卡」頁，看到「加到主畫面」提示就按「安裝」；沒出現的話，按右上角 ⋮ →「加到主畫面」 |
| **iPhone（Safari）** | 開啟「打卡」頁 → 下方「分享」按鈕 →「加入主畫面」 |

之後從手機桌面的「打卡」圖示打開，就像一個 App。

---

## 3. 打卡

### 上班／下班
1. 打開「打卡」
2. 手機詢問定位時，選 **允許**
3. 按 **上班打卡**；下班時按 **下班打卡**
4. 畫面會顯示時間與距離公司幾公尺

| 狀況 | 說明 |
|---|---|
| 顯示「異常」 | 你離公司超過允許範圍，系統照樣記錄，但會通知主管 |
| 國定假日上班 | 工時自動算「國定假日加班」，不用另外申請 |
| 沒網路 | 打卡需要連線，畫面會提示；請換到有網路的地方再打 |

### 忘記打卡 → 補卡
1. 打卡頁 → **補卡申請**
2. 選類型（補上班／補下班／兩者）、填正確時間與原因
3. 送出後等主管核准，核准後出勤自動更正

> 只能替自己補卡，不能替別人申請。

---

## 4. 我的工作

主管派給你的工序都在這裡。

| 按鈕 | 什麼時候按 | 結果 |
|---|---|---|
| **開始** | 開工時 | 狀態變「進行中」 |
| **卡關** | 缺稿、缺料、等客戶回覆等 | 必須填原因，主管會收到通知 |
| **繼續** | 問題解決後 | 回到「進行中」 |
| **完成** | 做完時 | 狀態變「完成」，下一站就能接手 |

> 請養成「開工按開始、做完按完成」的習慣，看板和交期提醒才會準。
> 只能操作派給自己的工序；別人的工序按不了是正常的。

---

## 4.5 快單（LINE）

臨時、散客的小單叫「快單」。綁定 LINE 後，在公司官方帳號的對話視窗：

| 要做什麼 | 輸入或按 |
|---|---|
| 幫客人開單 | `快單 名片2盒 王先生 0912345678 今天5點`（老闆會收到通知並派工） |
| 附上稿件照片 | 先傳照片，10 分鐘內再傳「快單 …」 |
| 收到派工 | 按通知下方的「開始做」，做完按「做好了」 |
| 客人來拿、收錢 | `收款 2610001 600`（轉帳：`收款 2610001 600 轉帳`） |
| 看還有哪些快單 | 傳 `快單` |

網頁版在「訂單與派工 → 快單看板」，操作相同。

## 4.6 接工作（誰有空誰接）

- LINE 收到「**有新工作可接**」時，有空就按「**我來做**」，做完按「**做好了**」。
- 也可以在 LINE 傳「**工作**」，看現在可以接的工作和自己手上的工作。
- 網頁「我的工作」上方有「可以接的工作」，按「我來做」接下。
- 別人先接走的工作，按了會提示「已被某某接走」。
- 你完成的工作會自動記錄，作為每月績效。

## 5. 派工看板

- 一欄一個站別（接單、設計、校稿、輸出製版、印刷、後加工、品檢包裝、出貨）
- 卡片會標示狀態：待排工、已指派、進行中、卡關、等客戶、外包中、完成
- 別人更新進度，你的畫面會自動跟著變，不用重新整理
- 工廠電視上的是「電視看板」，內容一樣，字比較大

---

## 6. 通知與 LINE

### 站內通知
右上角 🔔 的數字是未讀數，點開可看內容、點一下跳到相關頁面。

### 綁定 LINE（只要做一次）
1. 側邊欄最下方「個人設定」→「LINE 通知」卡片裡的 **6 碼綁定碼**
2. 用 LINE 加入公司官方帳號好友（QR code 向主管索取）
3. 在聊天室**傳送那 6 碼**
4. 收到「綁定成功」就完成了

綁定後，派工、卡關、異常打卡等通知會推到你的 LINE。

> 換手機或換 LINE 帳號：先在個人設定按「解除綁定」，再請主管重新產生綁定碼。
> 綁定碼不要給別人，否則別人會收到你的通知。

---

## 7. 個人設定

- 改密碼
- 看自己的 LINE 綁定狀態
- 姓名、電話要改請找主管

## 8. 常見問題

| 問題 | 解決 |
|---|---|
| 為什麼看不到「訂單」「應付」？ | 那些是主管功能，員工看不到是正常的 |
| 打卡一直顯示異常 | 確認手機定位已開、允許瀏覽器取得位置；仍異常就申請補卡並告知主管 |
| 按「完成」沒反應 | 這道工序可能不是派給你的，或已被別人完成；重新整理看看 |
| 收不到 LINE | 到個人設定看是否「已綁定」；沒有就重新傳綁定碼 |
| 手機主畫面圖示打不開 | 刪掉圖示，用瀏覽器重新開打卡頁，再加一次 |
