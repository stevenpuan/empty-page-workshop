### 狀態機（合法轉換）

```
pending → assigned / in_progress / skipped
assigned → in_progress / skipped
in_progress → done / blocked / waiting_customer / outsourced / skipped
blocked → in_progress / skipped
waiting_customer → in_progress / skipped
outsourced → done / in_progress
```

### RPC 函式簽章

| 函式 | 參數 | 誰可呼叫 | 說明 |
|------|------|----------|------|
| `task_start(uuid)` | task_id | assignee 或 manager | pending/assigned → in_progress |
| `task_done(uuid)` | task_id | assignee 或 manager | in_progress → done，回傳 order_all_done |
| `task_block(uuid, text)` | task_id, reason | assignee 或 manager | in_progress → blocked（reason 必填） |
| `task_assign(uuid, uuid)` | task_id, assignee_id | manager only | 指派員工，pending 自動變 assigned |
| `task_skip(uuid)` | task_id | manager only | 跳過工序 |

所有函式回傳 `jsonb`，格式：`{ ok: true, task_id, new_status, ... }`

- `board` 模組：owner/manager 全權限，staff 只讀
- `my_work` 模組：owner/manager/staff 皆可讀可編輯

### 指令 B：Realtime Hook

```
建立新檔案 src/hooks/useBoardRealtime.ts

這是看板的 Realtime 訂閱 hook，讓看板即時更新。

功能：
- 訂閱 supabase channel 'board'，監聽 order_tasks 表的 postgres_changes（event: '*'）
- 收到事件後，invalidate react-query 的 ['board_tasks'] queryKey
- 元件 unmount 時自動 unsubscribe

程式碼模式：
import { useEffect } from 'react'
import { useQueryClient } from '@tanstack/react-query'
import { supabase } from '@/lib/supabase'

export function useBoardRealtime() {
  const qc = useQueryClient()
  useEffect(() => {
    const channel = supabase
      .channel('board')
      .on('postgres_changes',
        { event: '*', schema: 'public', table: 'order_tasks' },
        () => { qc.invalidateQueries({ queryKey: ['board_tasks'] }) }
      )
      .subscribe()
    return () => { supabase.removeChannel(channel) }
  }, [qc])
}

在 board.tsx 的 Page 元件內呼叫 useBoardRealtime()。
```
