# 祥興／沂融 營運系統 — 管理者操作手冊 v1.0

> 對象：老闆、主管（manager 以上）
> 員工日常操作請見《員工操作手冊》；本手冊只寫管理者才有的功能。
> 版本日期：2026-10-16

---

## 0. 角色與權限一覽

| 角色 | 能做什麼 |
|---|---|
| 老闆（owner） | 全部功能；可切換祥興／沂融；看集團總覽與對帳 |
| 主管（manager） | 本公司全部營運功能：訂單、派工、外包、採購、應付應收、出勤核准、設定 |
| 員工（staff） | 我的工作、打卡、補卡申請、通知、個人設定；報價單（開單、改價、送出） |

細部權限在「設定 → 角色與權限」調整；畫面隱藏不算數，資料庫會再擋一次。

## 1. 每日開工

1. 打開 **營運總覽**：看今日新單、進行中、逾期工序
2. 打開 **派工看板**：把「待排工」的工序拖給負責人，或按卡片「指派」
3. 看 **通知鈴鐺**：外包回報、異常打卡、逾期提醒

老闆另外看 **集團總覽**：上方兩家並排的今日／本月數字，下方是兩家往來對帳。

## 1.5 誰有空誰接（派工方式）

- **建單：** 訂單與工單 → 新增 → 填好後按「**建立並開工**」。工序自動展開（預設三步：設計 → 製作 → 出貨），不用再按確認、不用逐道派工。還沒談定的單按「存草稿」，之後在列表「⋯ → 開工」。
- **設計：** 建單時可選「設計由誰做」；不選就給預設設計人員（工序站別設定），沒有預設就大家接。
- **其他工序不指定人：** 輪到那一步時，全公司 LINE 收到「有新工作可接」，誰有空按「**我來做**」，做完按「**做好了**」，下一步自動通知大家。
- 網頁上一樣：派工看板、我的工作都有「我來做」「做好了」；看板每張訂單只顯示輪到的那一步。
- 主管仍可在看板「指派」或拖拉卡片處理例外。
- **績效統計：** 訂單與派工 →「績效統計」，每月每人完成幾道工序、準時率、完成快單、經手快單營收，可匯出 Excel。

## 2. 訂單 → 出貨 → 應收

| 步驟 | 在哪裡 | 說明 |
|---|---|---|
| 報價 | 報價單 → 新增 | 填明細，小計／稅額／合計自動計算；可標記「已報價」「已接受」。已接受的報價按 **轉訂單**，自動建立訂單草稿 |
| 建單 | 訂單與工單 → 新增 | 選客戶、產品。**沒選工序範本時，系統依產品預設範本自動帶入** |
| 金額 | 同上 | 填未稅金額，稅額自動帶 5%（免稅可改 0）；含稅總額由系統計算 |
| 確認 | 訂單列「確認」 | 草稿 → 進行中，自動展開工序（交期往前倒推每道工序日期） |
| 作廢 | 訂單列「作廢」 | 草稿或進行中可作廢；有進行中的外包要先取消外包 |
| 出貨 | 工單明細 → 出貨單 → 開立出貨單 | 除了最後的「出貨」工序，其餘都完成才能開；系統自動：出貨工序完成、訂單轉已出貨、**產生應收**（到期日依客戶付款條件） |
| 列印 | 出貨單頁 → 列印 | A4 出貨單，含簽收欄 |
| 其他成本 | 工單明細 → 成本 → 新增 | 加班、運費等手動成本；進貨、領料、外包的成本系統會自動帶入，不用手打 |
| 作廢出貨單 | 出貨單頁 → 作廢（主管） | 應收尚未收款才能作廢；訂單回到進行中 |

> 員工在「我的工作」做完最後一道時，畫面會提示「開立出貨單」，按下去就到工單明細。

## 3. 外包

### 3.1 祥興 → 沂融（集團內）
1. 工單明細找到要外包的工序 → **派外包** → 選「沂融企業社」、填議定金額與交期
2. 沂融自動建單並展開工序；沂融主管收到通知
3. 沂融全部完工 → 祥興該工序自動完成，**祥興應付＝沂融應收** 同時產生，並寫入祥興工單成本
4. 沂融若拒接 → 祥興工序退回待排工，祥興主管收到通知

### 3.2 事後調整金額
外包追蹤 → 該筆 → **調整金額**（填原因）。系統同步改：議定金額、祥興應付、沂融應收、工單成本，並記錄在往來事件裡。已付款或已收款的要先作廢付款／收款。

### 3.3 外部廠商（非集團）
外包追蹤 → **外部廠商外包 → 建立進貨單**：選工序、廠商、金額，系統建立一張「直接進貨」草稿掛在該工單；廠商交貨後到進貨單按確認，即產生應付與工單成本。

## 3.5 快單（臨時、散客、做完收現）

取代便利貼派工。快單在左側「訂單與派工 → 快單看板」，祥興、沂融各自一個看板。

| 步驟 | LINE（公司官方帳號對話視窗） | 網頁（快單看板） |
|---|---|---|
| 開單（老闆、員工都可以） | `快單 名片2盒 王先生 0912345678 今天5點` | 右上「開快單」 |
| 附照片 | 先傳照片，10 分鐘內再傳「快單 …」 | 點卡片可看照片 |
| 派工（老闆、店長） | 收到新快單通知時，點下方員工名字；或開單時句尾加「給阿明」 | 卡片「派工」 |
| 開始／完成（被派的人） | 按通知下方「開始做」「做好了」，或傳 `完成 2610001` | 卡片「開始」「完成」 |
| 取件收款 | `收款 2610001 600`（轉帳加「轉帳」，之後再收加「未收」） | 卡片「取件收款」 |
| 取消 | `取消 2610001 客人不要了` | 卡片「⋯ → 取消快單」 |
| 看清單 | 傳 `快單` | 看板 |

- **金額在取件時才填。** 結案時系統自動產生應收（來源「快單」）；付現或轉帳同時收款沖帳，選「未收」就留在應收，之後到「應收與收款」收。
- **營收：** 以取件結案那天計入；集團總覽有「快單 今日營收／本月營收」。
- **日結：** 快單看板 →「日結」分頁，依收款人列出現金、轉帳、未收，現金那欄用來對收銀抽屜；可列印。
- **開沂融的單：** 訊息裡加「沂融」（例如 `快單 沂融 燙金卡片 50張`）；要在兩家都有員工資料才能開。
- **時間寫法：** 今天5點、明天上午10點、10/20 3點半；沒寫上午下午時，1～7 點視為下午。
- **工廠電視：** 快單看板右上「全螢幕」。
- 單號可以只打後 7 碼（例如 2610001）；兩家單號尾碼相同時請打完整單號（XX-QK-2610001）。

## 3.6 價目設定與報價（老闆不在時員工也能報價）

### 設定價目（左側「客戶與應收 → 價目設定」）
1. 打開《報價價目表範本.xlsx》，把藍色範例價格改成實際價格（金額一律未稅）。
2. 回到「價目設定」按右上「**上傳 Excel**」，確認畫面上各公司的筆數後按「確認匯入」。
   - 同一個檔案可以同時放祥興、沂融的價目（看「公司」欄）；兩家都要是老闆或有價目設定權限才能匯入。
   - 匯入會**整份取代**那家公司的價目；已開的報價單不受影響。
   - 檔案有錯會列出第幾列哪裡錯，改好再上傳。
3. 之後要調單一價格：直接在三個分頁按鉛筆圖示修改，或「匯出 Excel」改完再上傳。

| 計價方式 | 怎麼算 | 例 |
|---|---|---|
| 數量級距 | 數量落在哪一級就用那一級單價；比第一級少用第一級單價 | 名片 1～4 盒每盒 $380、5～9 盒每盒 $330 |
| 面積計價 | 每才單價 × 才數；才數＝寬×高÷918，不足 1 才算 1 才（每件分開算） | 帆布 90×180cm＝18 才 |
| 固定單價 | 單價 × 數量 | 影印每張 $1 |
| 需老闆報價 | 不算價，員工自己填 | 紙盒 |

- **最低收費：** 算出來低於最低收費時以最低收費計（加工另加）。
- **加工加價：** 每個計價單位（乘數量）、每才、每個（報價時填個數）、固定金額、總價加成（0.3＝加 30%，最後才加）。適用大類空白＝全部品項都能選。

### 報價與通知
- 員工在「報價單 → 新增報價」選大類、品項、價格選項，填數量（帆布、大圖填寬高），勾加工，系統帶出**建議價**；員工可以直接改金額，沒有上下限、不用核准。
- 現場客人選「散客」，再填聯絡人、電話。
- 按「**送出報價**」時，老闆、店長的 LINE 會收到通知：客戶、報價人、未稅／稅額／合計、每一筆明細；有改價的標出「建議價 $1,716，改低 $216（-13%）」，需老闆報價或自己填價的也會標出來。
- 「存草稿」不通知；草稿之後再送出才通知。
- 報價單展開明細有「建議價」欄，可以看出哪幾筆照建議價、哪幾筆改過。
- 通知可在「設定 → 通知規則 → 報價單送出」關掉或改成只發站內。

## 4. 採購、庫存、應付

| 功能 | 說明 |
|---|---|
| 進貨單 | 「庫存進貨」確認後自動入庫；「直接進貨」要選工單，確認後掛工單成本。金額由明細自動計算，確認後明細鎖定 |
| 庫存 | 看現有量、平均成本、低於安全量。**領料**可掛工單（自動記材料成本）；**盤點**輸入實際數量自動調整 |
| 應付與付款 | 見下方「4.1 收付款與沖帳」，操作與應收相同 |
| 匯出 Excel | 應收、應付頁「匯出未結 Excel」：未結清單含發票、逾期天數與合計 |

### 4.1 收付款與沖帳（應收、應付操作相同）

| 情境 | 怎麼做 |
|---|---|
| 客戶匯款、付廠商貨款 | 帳款列按 **收款／付款**（或右上「新增收款／付款」）→ 填實收（付）金額 → 勾選要沖的帳款，可改成部分沖帳；按 **自動分配** 會從最早到期的開始沖 |
| 客戶匯款被扣匯費 | 實收填實際入帳數，**手續費** 填被扣的匯費，兩者加起來沖掉帳款 |
| 議價少收／少付 | 填在 **折讓** |
| 先收訂金、先付預付款 | 沖帳不勾任何帳款，整筆記為 **預收／預付**；之後到「收款／付款紀錄」該筆按 **沖帳** |
| 尾差、確定收不到的壞帳 | 帳款列「⋯」→ **沖銷餘額**，必填原因；要還原就把那筆「沖銷」紀錄作廢 |
| 收錯、付錯 | 「收款／付款紀錄」→ **作廢**，金額自動反沖回帳款，沖帳明細保留並標示已作廢 |
| 期初帳款、雜項收入／費用 | 右上 **新增應收／應付**（手動）；手動帳款在沒有沖帳前可作廢 |
| 補發票號碼、改到期日 | 帳款列「⋯」→ **修改發票號碼／到期日**（金額不能改，要改請改出貨單、進貨單或外包金額） |

> 一筆收付款只能沖同一個客戶／廠商的帳款；帳務資料只能透過上述按鈕異動，不能直接改數字。

| 功能 | 說明 |
|---|---|
| 出勤與簽核 | 每日出勤、異常打卡、補卡核准、月彙總 |

## 7. 站別與範本

設定 → 工序站別與範本；產品在 設定 → 產品主檔。

- 祥興：接單 → 設計 → 校稿 → 輸出製版 → 印刷 → 後加工 → 品檢包裝 → 出貨
- 沂融：接件 → 製版輸出 → 印刷 → 燙金 → 裱板裁切 → 摺紙裝訂 → 後加工 → 品檢交件
- 範本名稱有「（測試）」的是暫定，易老闆確認後可直接改名、調整步驟

產品主檔可指定「預設範本」，建單時自動帶入。

## 8. 常見問題

| 狀況 | 處理 |
|---|---|
| 「訂單狀態請用系統按鈕變更」 | 狀態不能直接改，請用列上的確認／作廢／出貨 |
| 「還有未完成的工序，不能出貨」 | 到看板把前面工序完成或略過 |
| 「應付已付款，請先作廢付款」 | 到應付與付款，找那筆付款按作廢後再操作 |
| 員工說收不到 LINE | 員工頁看是否「已綁定」；未綁定就把綁定碼給他重傳 |
| 打卡一直顯示異常 | 公司座標尚未設定正確，或員工手機定位未開 |
