# 祥興／沂融 營運系統 — 管理者操作手冊 v1.0

> 對象：老闆、主管（manager 以上）
> 員工日常操作請見《員工操作手冊》；本手冊只寫管理者才有的功能。
> 版本日期：2026-10-16

---

## 0. 角色與權限一覽

| 角色 | 能做什麼 |
|---|---|
| 老闆（owner） | 全部功能；可切換祥興／沂融；看集團總覽與對帳 |
| 主管（manager） | 本公司全部營運功能：訂單、派工、外包、採購、應付應收、出勤核准、設定 |
| 員工（staff） | 我的工作、打卡、補卡申請、通知、個人設定 |

細部權限在「設定 → 角色與權限」調整；畫面隱藏不算數，資料庫會再擋一次。

---

## 1. 每日開工

1. 打開 **營運總覽**：看今日新單、進行中、逾期工序
2. 打開 **派工看板**：把「待排工」的工序拖給負責人，或按卡片「指派」
3. 看 **通知鈴鐺**：外包回報、異常打卡、逾期提醒

老闆另外看 **集團總覽**：上方兩家並排的今日／本月數字，下方是兩家往來對帳。

## 2. 訂單 → 出貨 → 應收

| 步驟 | 在哪裡 | 說明 |
|---|---|---|
| 建單 | 訂單與工單 → 新增 | 選客戶、產品。**沒選工序範本時，系統依產品預設範本自動帶入** |
| 金額 | 同上 | 只填未稅與稅額；含稅總額由系統計算 |
| 確認 | 訂單列「確認」 | 草稿 → 進行中，自動展開工序（交期往前倒推每道工序日期） |
| 作廢 | 訂單列「作廢」 | 草稿或進行中可作廢；有進行中的外包要先取消外包 |
| 出貨 | 工單明細 → 出貨單 → 開立出貨單 | 除了最後的「出貨」工序，其餘都完成才能開；系統自動：出貨工序完成、訂單轉已出貨、**產生應收**（到期日依客戶付款條件） |
| 列印 | 出貨單頁 → 列印 | A4 出貨單，含簽收欄 |
| 作廢出貨單 | 出貨單頁 → 作廢（主管） | 應收尚未收款才能作廢；訂單回到進行中 |

> 員工在「我的工作」做完最後一道時，畫面會提示「開立出貨單」，按下去就到工單明細。

---

## 3. 外包

### 3.1 祥興 → 沂融（集團內）
1. 工單明細找到要外包的工序 → **派外包** → 選「沂融企業社」、填議定金額與交期
2. 沂融自動建單並展開工序；沂融主管收到通知
3. 沂融全部完工 → 祥興該工序自動完成，**祥興應付＝沂融應收** 同時產生，並寫入祥興工單成本
4. 沂融若拒接 → 祥興工序退回待排工，祥興主管收到通知

### 3.2 事後調整金額
外包追蹤 → 該筆 → **調整金額**（填原因）。系統同步改：議定金額、祥興應付、沂融應收、工單成本，並記錄在往來事件裡。已付款或已收款的要先作廢付款／收款。

### 3.3 外部廠商（非集團）
外包追蹤 → **外部廠商外包 → 建立進貨單**：選工序、廠商、金額，系統建立一張「直接進貨」草稿掛在該工單；廠商交貨後到進貨單按確認，即產生應付與工單成本。

## 4. 採購、庫存、應付

| 功能 | 說明 |
|---|---|
| 進貨單 | 「庫存進貨」確認後自動入庫；「直接進貨」要選工單，確認後掛工單成本。金額由明細自動計算，確認後明細鎖定 |
| 庫存 | 看現有量、平均成本、低於安全量。**領料**可掛工單（自動記材料成本）；**盤點**輸入實際數量自動調整 |
| 應付與付款 | 一筆付款可沖多張應付（可部分付款）；付款作廢自動反沖 |
| 匯出 Excel | 應付頁右上「匯出 Excel」：未付清單含逾期天數與合計 |

## 5. 出勤

| 功能 | 說明 |
|---|---|
| 出勤與簽核 | 每日出勤、異常打卡、補卡核准、月彙總 |
| 假日行事曆 | 設定 → 假日行事曆。國定假日或公司休假當天上班，工時**全部列為國定假日加班**、不算遲到早退。系統預填 2026 Q4–2027 國定假日（標「待確認」），請依人事行政總處公告確認 |
| 打卡範圍 | 設定 → 公司設定：座標與半徑（目前為佔位值，**上線前務必改成店址**） |
| 手機主畫面 | 員工用手機開打卡頁，依提示「加到主畫面」即可像 App 一樣開啟 |

## 6. 人員與 LINE

| 功能 | 說明 |
|---|---|
| 新增員工 | 設定 → 員工與帳號 → 新增；再按「建立帳號」給登入帳密 |
| LINE 綁定 | 員工頁顯示每人 6 碼綁定碼 → 員工加官方帳號好友、傳綁定碼即完成。可重新產碼、解除綁定 |
| 通知規則 | 設定 → 通知規則：每條可開關站內／LINE、即時或每日摘要、收件對象 |

## 7. 站別與範本

設定 → 工序站別與範本。

- 祥興：接單 → 設計 → 校稿 → 輸出製版 → 印刷 → 後加工 → 品檢包裝 → 出貨
- 沂融：接件 → 製版輸出 → 印刷 → 燙金 → 裱板裁切 → 摺紙裝訂 → 後加工 → 品檢交件
- 範本名稱有「（測試）」的是暫定，易老闆確認後可直接改名、調整步驟

產品主檔可指定「預設範本」，建單時自動帶入。

## 8. 常見問題

| 狀況 | 處理 |
|---|---|
| 「訂單狀態請用系統按鈕變更」 | 狀態不能直接改，請用列上的確認／作廢／出貨 |
| 「還有未完成的工序，不能出貨」 | 到看板把前面工序完成或略過 |
| 「應付已付款，請先作廢付款」 | 到應付與付款，找那筆付款按作廢後再操作 |
| 員工說收不到 LINE | 員工頁看是否「已綁定」；未綁定就把綁定碼給他重傳 |
| 打卡一直顯示異常 | 公司座標尚未設定正確，或員工手機定位未開 |
