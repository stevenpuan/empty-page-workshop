## 3. 驗收步驟（Steven 在 Lovable 預覽或發布網址操作）

1. 開 `/login`：公司下拉應列出「祥興數位影印廣告印刷」「沂融企業社」，頂端色條隨公司變色。
2. 以平台管理員登入（帳號 `steven05@puansage.net`，臨時密碼另行提供）→ 應先看到「請先修改密碼」整頁 → 改完進入首頁。
3. 側欄應有：營運總覽、設定（六項）、系統（六項）、通知中心、個人設定；左上公司切換器可切祥興↔沂融。
4. 「員工與帳號」：在祥興新增易老闆（編號例 `A01`，角色「老闆」，勾「可切換公司」）→ 按「建立帳號」→ 記下臨時密碼。切到沂融，再新增一筆易老闆（同編號、角色「老闆」）→ 建立帳號 → 應顯示「已綁定既有帳號」。
5. 用易老闆帳號另開無痕視窗登入 → 改密碼 → 應看到公司切換器；「角色與權限」可勾選；「公司設定」可存。
6. 在祥興新增一位員工（角色「員工」）→ 建帳 → 用該帳號登入：側欄只剩營運總覽／通知／個人設定（S1 尚無派工看板），直接輸入 `/dashboard/settings/roles` 應顯示「沒有權限檢視此頁」。
7. 沂融員工登入後，直接輸入 `/dashboard/quotations` 應顯示「本公司未啟用此功能」。
8. 「系統／稽核日誌」（平台管理員或老闆）：應看到 create_account、reset_password 等紀錄。
9. Supabase Dashboard → SQL Editor 整份執行 `supabase/verify/004_verify.sql`：訊息應為「失敗 0 項 → 全部通過 ✅」。
